# 红序 - 小红书个人 IP 运营与素材系统

本项目包含两个部分：

- Web 工作台：素材中心作为独立业务入口，个人 IP 运营包含账号登录、图片设计、内容库、内容审查、发布计划、待处理消息、数据分析和竞品观测等功能。信息流矩阵入口目前已关闭，历史数据仍保留以便后续恢复。
- 本地执行器：连接百度网盘并管理本机素材缓存，也使用本机 Chrome 的独立持久会话登录小红书创作服务平台，执行图片上传、标题/正文填写、定时发布和账号异常暂停。

## 启动

打开两个终端，分别运行：

```bash
npm run dev
```

```bash
npm run runner
```

访问 `http://localhost:3000`。

## 图片素材库（当前推荐入口）

启动 Web 工作台和本地执行器后，进入“素材中心”。素材库支持：

- 一次选择多张图片上传，自动生成缩略图，并使用内容指纹跳过重复图片；
- 自主创建标签组和标签，单张或批量设置主图、次图及多个标签；
- 按文件名、用途、使用状态和多个标签组合筛选；
- 从素材库选择图片组成内容项目，第 1 张作为主图，其余作为次图；
- 拖动或使用上下箭头调整图片顺序，保存内容标题与草稿/完成状态；
- 查看每张图片被哪些内容使用，以及在内容中的位置；
- 导出按 `01-主图`、`02-次图` 顺序命名的 ZIP 图片包。

图片原件、缩略图、标签和内容项目默认保存在 `runner/data/material-library/`。该目录不会提交到 Git。需要备份时，请在关闭本地执行器后完整复制这个目录；需要放到其他磁盘时，可在 `.env.local` 中配置 `MATERIAL_LIBRARY_DIR`。

当前交付采用本地持久化方案，不需要购买服务器即可使用。存储层和业务数据已经分离，未来迁移到对象存储和在线数据库时，界面和日常操作流程无需重做。

## 连接百度网盘素材库

1. 在[百度网盘开放平台](https://yun.baidu.com/open/platform)创建应用，取得 App Key 和 Secret Key。
2. 把授权回调地址配置为 `http://127.0.0.1:3100/api/materials/baidu/callback`。
3. 复制 `.env.example` 为 `.env.local`，填写 `BAIDU_PAN_APP_KEY` 和 `BAIDU_PAN_APP_SECRET`。
4. 如果只希望红序读取特定文件夹，在 `BAIDU_PAN_ROOT_PATH` 中填写该文件夹的完整网盘路径。
5. 重新启动本地执行器，进入“素材中心”，点击“连接百度网盘”完成官方授权。

百度网盘保存云端原件。本机只缓存正在制作或即将发布的素材，默认上限为 80 GB。可以通过 `MATERIAL_CACHE_MAX_GB` 修改上限，也可以使用 `MATERIAL_CACHE_DIR` 把缓存放到外接硬盘。

清理本机缓存不会删除百度网盘原件。授权令牌和本机缓存记录保存在 `runner/data/`，该目录不会进入 Git。

### 整理网盘素材

素材中心支持新建虚拟素材夹、批量勾选素材，以及为同一素材添加多个标签。虚拟归类只保存轻量索引，不复制文件，也不会改变百度网盘中的原件位置。

虚拟素材夹最多支持两级。在百度网盘目录中，可以把单个素材或整个百度网盘文件夹拖到顶部的一级、二级素材夹；拖入整个文件夹后，系统会在后台扫描其中所有子目录，并把图片和视频加入目标虚拟素材夹。这个过程仍然只建立索引，不会下载或移动原件。

如果确实需要整理百度网盘本身的文件夹，可以在“批量归类”窗口中打开“同时移动百度网盘原件”，填写素材根目录内的目标文件夹，并完成两次确认。同名文件不会被覆盖，单次最多移动 50 个图片或视频原件；操作结果会保留在本机运行记录中。

## 视频截帧

视频需要先缓存到本机。项目依赖会自动下载适配当前电脑的 FFmpeg，素材中心会优先使用它按指定时间点截取 JPG，并直接加入当前草稿；不需要再单独配置系统环境。如果确实需要改用其他版本，可以在 `.env.local` 中设置 `FFMPEG_PATH`。图片缓存和图文发布不受视频处理组件影响。

## 图片设计

进入“图片设计”即可在 1080 × 1440 的小红书 3:4 画布中制作封面和内页。当前支持：

- 上传单张或多张图片、铺满主图、上下拼接和四宫格；
- 根据 5 张参考案例制作的人物爆款封面、粉丝权益四宫格、服务说明大图、电影感案例和上下拼接模板；
- 文字、色块、圆形、星形、三角形、箭头、爆炸贴、波浪线和自定义图片贴图；
- 图层顺序、拖动、缩放、复制、撤销和重做；
- 文字颜色、黑色描边、阴影、红底标签、字体大小、行高和对齐；
- 上传 TTF、OTF、WOFF、WOFF2 或 TTC 字体包，连接本地执行器后会长期保存在 `runner/data/fonts/`；
- 图片圆角、透明度、边框、亮度、对比度、饱和度、焦点位置和水平/垂直翻转；
- 在浏览器本机运行 AI 自动抠图，输出透明 PNG，不会把图片发到第三方抠图服务；
- 每次编辑后自动保存当前业务的画布和上传图片，重新进入时恢复；
- 下载高清 PNG，或点击“保存并加入草稿”把成图保存到 `runner/data/designs/` 并直接回到发布草稿台。

在“素材中心”中，本机可用的图片也可以直接点击“作图”进入画布，不需要先下载再重新上传。

## 真实账号登录

1. 进入“账号与登录”。
2. 点击对应账号的“发起登录”。
3. 系统会打开独立 Chrome 窗口并进入小红书创作服务平台。
4. 人工完成扫码、短信、设备验证或验证码。
5. 返回系统点击“检查状态”。

每个账号的 Chrome 会话保存在本机 `runner/.sessions/`，该目录已被 Git 忽略。系统不记录密码和验证码。

## 自动发布

1. 内容先在“内容审查”中通过。
2. 从“素材中心”把已经缓存的图片或视频截帧加入草稿，也可以继续手工填写图片绝对路径。
3. 点击“确认并加入队列”，再次确认真实发布。
4. 本地执行器在计划时间打开官方创作平台并执行发布。

平台页面结构变化、登录失效、安全验证或账号异常可能阻止自动发布。执行器会暂停账号队列并要求人工处理，不会绕过平台验证或自动申诉。
