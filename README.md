# 红序 - 小红书双业务运营与素材系统

本项目包含两个部分：

- Web 工作台：信息流矩阵与个人 IP 两个一级业务菜单，下面分别展示账号登录、素材中心、内容库、内容审查、发布计划、待处理消息、数据分析和竞品观测等二级菜单。
- 本地执行器：连接百度网盘并管理本机素材缓存，也使用本机 Chrome 的独立持久会话登录小红书创作服务平台，执行图片上传、标题/正文填写、定时发布和账号异常暂停。

## 启动

打开两个终端，分别运行：

```bash
npm run dev
```

```bash
npm run runner
```

访问 `http://localhost:3000`。

## 连接百度网盘素材库

1. 在[百度网盘开放平台](https://yun.baidu.com/open/platform)创建应用，取得 App Key 和 Secret Key。
2. 把授权回调地址配置为 `http://127.0.0.1:3100/api/materials/baidu/callback`。
3. 复制 `.env.example` 为 `.env.local`，填写 `BAIDU_PAN_APP_KEY` 和 `BAIDU_PAN_APP_SECRET`。
4. 如果只希望红序读取特定文件夹，在 `BAIDU_PAN_ROOT_PATH` 中填写该文件夹的完整网盘路径。
5. 重新启动本地执行器，进入“素材中心”，点击“连接百度网盘”完成官方授权。

百度网盘保存云端原件。本机只缓存正在制作或即将发布的素材，默认上限为 80 GB。可以通过 `MATERIAL_CACHE_MAX_GB` 修改上限，也可以使用 `MATERIAL_CACHE_DIR` 把缓存放到外接硬盘。

清理本机缓存不会删除百度网盘原件。授权令牌和本机缓存记录保存在 `runner/data/`，该目录不会进入 Git。

## 视频截帧

视频需要先缓存到本机。素材中心会使用本机 FFmpeg 按指定时间点截取 JPG，并直接加入当前草稿。如果界面提示视频处理组件不可用，请先在本机安装 FFmpeg；图片缓存和图文发布不受影响。

## 真实账号登录

1. 进入“账号与登录”。
2. 点击对应账号的“发起登录”。
3. 系统会打开独立 Chrome 窗口并进入小红书创作服务平台。
4. 人工完成扫码、短信、设备验证或验证码。
5. 返回系统点击“检查状态”。

每个账号的 Chrome 会话保存在本机 `runner/.sessions/`，该目录已被 Git 忽略。系统不记录密码和验证码。

## 自动发布

1. 内容先在“内容审查”中通过。
2. 从“素材中心”把已经缓存的图片或视频截帧加入草稿，也可以继续手工填写图片绝对路径。
3. 点击“确认并加入队列”，再次确认真实发布。
4. 本地执行器在计划时间打开官方创作平台并执行发布。

平台页面结构变化、登录失效、安全验证或账号异常可能阻止自动发布。执行器会暂停账号队列并要求人工处理，不会绕过平台验证或自动申诉。
